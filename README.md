# Computational Chemistry & Scientific Computing

**Chemical Engineering PhD | Professional Engineer | Computational Scientist**

I am a computational scientist and chemical engineer with expertise in density functional theory (DFT), heterogeneous catalysis, microkinetic modeling, numerical methods, and high-performance computing.

My doctoral research at Oregon State University investigated catalytic reactions on palladium surfaces, including acetic acid decomposition and ammonia synthesis. I developed computational approaches for modeling coverage-dependent adsorption energetics, including polyharmonic-spline interpolation, higher-precision numerical calculations, and sensitivity analysis using automatic differentiation.

My professional background also includes environmental regulatory engineering, technical data systems, software development, and engineering project coordination.

## Research Interests
